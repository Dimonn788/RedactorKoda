🛠️ О Проекте Code Runner Pro

**Code Runner Pro** — это простой и быстрый инструмент для моментального тестирования HTML и CSS кода прямо в вашем браузере. Наша миссия — предоставить разработчикам, студентам и всем, кто изучает веб-технологии, чистую и удобную песочницу для экспериментов.

Наши Принципы

Мы верим в минимализм и эффективность. Наш редактор не требует регистрации, скачивания или сложной настройки. Вы просто открываете страницу, пишете код и мгновенно видите результат.

  • **Мгновенный результат:** Код отображается без задержек.
  • **Тёмная тема:** Максимальный комфорт для глаз.
  • **Локальное использование:** Инструмент работает прямо с вашего компьютера.
